# CastleWalk Tickets

Sistema interno de solicitudes para empleados de CastleWalk. Cualquiera crea un ticket hacia un área; el gerente o gestor de esa área asigna el trabajo y decide quién puede cerrarlo.

## Quick path

1. [Levantar el entorno](getting-started.md)
2. Entrar con una [cuenta demo](getting-started.md#cuentas-demo)
3. Crear un ticket, asignarlo y cerrarlo siguiendo el [flujo de uso](usage.md)
